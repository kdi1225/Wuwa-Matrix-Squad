# Wuwa Matrix Squad

**명조: 워더링 웨이브 · 종말 매트릭스 파티 편성 도구**

보유한 공명자로 여러 파티를 미리 구성하고, 캐릭터별 편성 횟수를 한눈에 확인하세요.

### [사이트 바로가기 →](https://kdi1225.github.io/Wuwa-Matrix-Squad/)

## 주요 기능

- **드래그 편성** — 도감의 캐릭터를 파티 슬롯으로 끌어 배치합니다. 클릭이나 터치로도 편성할 수 있습니다.
- **보유 공명자 설정** — 보유한 캐릭터를 저장하고, 도감에 보유한 캐릭터만 표시할 수 있습니다.
- **속성별 필터** — 회절·기류·전도·용융·응결·인멸 속성으로 도감을 필터링합니다. 보유 필터와 함께 사용할 수 있습니다.
- **파티 관리** — 파티를 추가·삭제하고 순서를 변경할 수 있습니다. 편성한 캐릭터의 위치 이동과 교환도 지원합니다.
- **주기별 추가 편성** — 이번 주기에 2회 편성이 허용되는 캐릭터를 직접 지정합니다.
- **자동 저장** — 보유 목록, 파티, 필터, 주기 설정이 브라우저를 껐다 켜도 유지됩니다.

## 사용 방법

1. **보유 공명자 설정**에서 보유한 캐릭터를 선택하고 저장합니다. 필요한 경우 **보유만 보기**를 켭니다.
2. 왼쪽 도감의 캐릭터를 오른쪽 **나의 파티** 슬롯으로 드래그합니다. 캐릭터를 선택한 뒤 슬롯을 눌러도 배치됩니다.
3. **새로운 파티 추가**로 파티를 늘립니다. 파티의 캐릭터를 끌어 이동·교환하고, 손잡이나 위·아래 버튼으로 파티 순서를 조정합니다.
4. **이번 주기 추가 편성 → 대상 설정**에서 해당 주기의 추가 편성 대상 캐릭터를 선택합니다.

캐릭터 사진의 **×** 버튼은 편성 해제, 파티의 **삭제** 버튼은 파티 제거입니다. 도감의 **사용 / 최대** 표시로 남은 편성 횟수를 확인할 수 있습니다.

## 편성 규칙

| 구분 | 최대 편성 횟수 |
| --- | --- |
| 일반 공명자 | 1회 |
| 서포터 공명자 | 2회 |
| 주기별 추가 편성 대상 | 2회 |

서포터는 **설지, 벨리나, 파수인, 복링, 모니에, 수수, 릴리**입니다. 같은 파티 안에서는 동일한 캐릭터를 중복 편성할 수 없습니다.

주기별 추가 편성 대상을 해제하려면 해당 캐릭터의 사용 횟수를 먼저 1회 이하로 줄여주세요.

## 저장 안내

설정과 편성 정보는 **사용 중인 브라우저에 자동 저장**됩니다. 같은 브라우저·프로필에서 사이트를 다시 열면 이전 상태가 복원됩니다.

다른 기기나 브라우저와 자동으로 공유되지는 않으며, 브라우저의 사이트 데이터를 삭제하면 저장된 정보도 초기화됩니다.

## 현재 반영 사항

- 방랑자는 속성별로 편성 횟수를 따로 계산합니다.
- 릴리는 목록에 포함되어 있으며, 현재 임시 초상 이미지로 표시됩니다.
- 주기별 추가 편성 대상은 자동으로 갱신되지 않습니다. 게임 내 해당 주기의 정보를 확인해 직접 설정해주세요.
