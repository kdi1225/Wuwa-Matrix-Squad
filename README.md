# Wuwa Matrix Squad

명조 종말 매트릭스의 파티를 미리 편성하는 비공식 팬 도구입니다. 별도 라이브러리 설치 없이 HTML, CSS, JavaScript로 동작합니다.

## 로컬 실행

Node.js 20 이상이 설치된 환경에서 프로젝트의 `start.cmd`를 실행하거나 다음 명령을 사용합니다.

```sh
npm start
```

브라우저에서 http://127.0.0.1:4173 을 엽니다. 종료하려면 서버 터미널에서 Ctrl+C를 누릅니다. 매번 같은 주소와 포트를 사용해야 기존 브라우저 저장 정보를 불러옵니다.

## 사용 방법

- 왼쪽 도감에서 공명자를 오른쪽 파티 슬롯으로 드래그합니다. 캐릭터를 클릭한 후 슬롯을 눌러도 편성됩니다.
- 일반 캐릭터는 1회, 서포터는 2회 편성할 수 있습니다. 같은 파티 내 중복 편성은 허용하지 않습니다.
- 서포터: 설지, 벨리나, 파수인, 복링, 모니에, 수수, 릴리.
- `이번 주기 추가 편성 → 대상 설정`에서 일반 캐릭터의 사용 한도를 2회로 지정합니다. 이미 2회 사용한 캐릭터는 먼저 1회 이하로 줄여야 주기 대상에서 제외할 수 있습니다.
- `보유 공명자 설정`에서 소유한 캐릭터를 고르고 저장합니다. `보유만 보기`와 속성 필터는 함께 적용됩니다. 취소 및 Esc는 팝업의 임시 변경을 저장하지 않습니다.
- 파티 내 캐릭터를 끌어 이동하거나 교환할 수 있습니다. 캐릭터의 ×는 편성 해제, 파티의 삭제는 파티 제거입니다. 파티는 드래그 손잡이나 위·아래 버튼으로 정렬합니다.
- 보유 목록, 필터, 주기 설정, 파티는 `localStorage`에 자동 저장됩니다. 동일한 브라우저·프로필·사이트 주소에서 유지됩니다. 기기 간 동기화는 제공하지 않습니다.

## 데이터 및 이미지

- `src/data.js`: 공명자 이름, 속성, 서포터 지정, 이미지 연결. 사용자가 제공한 도감 목록을 기준으로 61개 항목을 등록했습니다.
- `public/images/characters/`: 원본 WebP 캐릭터 이미지. 임시 수신 폴더 `image-inbox/`는 Git에서 제외합니다.
- 릴리는 이미지가 없어 임시 실루엣을 표시합니다. 추후 `릴리.webp`를 추가하고 데이터의 이미지 항목을 연결하면 됩니다.
- 방랑자 네 속성은 현재 **개별 편성 항목으로 계산**합니다. 제공된 동일한 초상화 하나를 공용으로 참조합니다. 속성 간 횟수 공유 규칙은 아직 확정되지 않았습니다.
- 현재 주기의 실제 추가 편성 대상은 초기값으로 지정하지 않았습니다. 설정 팝업에서 직접 선택합니다.

## 검증 및 배포 준비

```sh
npm test
npm run build
```

`dist/`에 정적 사이트가 생성됩니다. 상대 경로를 사용하므로 GitHub Pages의 프로젝트 하위 경로에도 배포할 수 있습니다. 이 프로젝트에서 GitHub 저장소 생성·푸시·배포는 아직 수행하지 않았습니다.

회로 선택, 이미지 내보내기, 공유 링크 등은 이번 구현 범위에 포함하지 않았습니다.

게임 및 캐릭터 이미지의 권리는 원저작권자에게 있습니다.
